1 Для запуска БД выполните в cmd при запущенном докере команду (для windows):
docker run -d --name t1-demo ^
  -e POSTGRES_PASSWORD=0000 ^
  -e POSTGRES_DB=t1_demo ^
  -p 5432:5432 ^
  postgres

2 Инициализация тестовых данных происходит после запуска проекта классом DataGenerator. 
Тестовые данные обновляются после каждого перезапуска проекта.
